One macOS menu bar item that shows what is left on your AI API accounts. It
shows one account at a time and rotates every minute; click it and every account
is shown at once.

```
Q 42% · 2d        →  a minute later  →        D ¥110.00
```

## Accounts in this release

| | Service | Credential | Shows |
|---|---|---|---|
| `Q` | QwenCloud Token Plan | console sign-in | remaining 7-day allowance, reset countdown |
| `D` | DeepSeek API | API key | balance, peak/off-peak rate band |

The drop-down stays deliberately short — for each account, what is left and when
that changes:

```
Q  QwenCloud Token Plan          D  DeepSeek API
     Left: 42%                        Balance: ¥110.00
     Resets in 2d                     Off-peak (50% off) · peak in 4h
     Open Console                     Open Usage Page
     Sign Out
```

The reading turns red when an account is running low, and grey with a `⚠` when
its last refresh failed. Adding another service is a folder under
`Sources/TokenBar/Providers/` plus one line in `ProviderRegistry`.

## Also in this release

- Low-balance notifications, launch at login, and a per-account "show in menu
  bar" toggle.
- Today's DeepSeek spend as an optional second figure in the menu bar title,
  from the DeepSeek settings tab.
- A daily check for new versions. It only tells you one exists — nothing is
  downloaded or installed for you, and it can be turned off in Settings.

## How DeepSeek spend is worked out

DeepSeek publishes a balance endpoint but no usage endpoint every account can
reach. TokenBar tries the undocumented `/v1/usage` once; when the account has
it, spend is exact. When it does not, spend is estimated from a **balance
ledger** — each drop in the balance is treated as spending, with any top-up in
the same interval added back, and granted credit that expires on its own
excluded.

Wallets in different currencies are never converted and never added together.

## Install

Download the `.dmg`, drag `TokenBar.app` into `Applications`, then clear the
quarantine flag once — the app is **not notarized** (that needs a paid Apple
Developer ID), so macOS will otherwise refuse to open it:

```bash
xattr -dr com.apple.quarantine /Applications/TokenBar.app
```

Universal binary (Apple Silicon + Intel), macOS 13 or later.

### Coming from QwenTokenBar

TokenBar has its own bundle identifier, so it has its own cookie store and
preferences — **you will need to sign in to QwenCloud once more**. The
standalone [QwenTokenBar](https://github.com/Vik1n9/QwenTokenBar) is unaffected;
run either, or both.

## Privacy

The DeepSeek API key is stored in the login keychain, never in preferences, the
ledger file, or any log. The only network traffic is to the endpoints of the
accounts you configure, plus one request a day to GitHub's public release API
when update checking is on. No analytics, no telemetry.
