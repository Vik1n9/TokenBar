First release of TokenBar — a macOS menu bar app that shows how much allowance
or credit each of your AI API accounts has left, without opening a console in a
browser.

Unofficial tool. Not affiliated with, endorsed by, or sponsored by any of the
services it reads from.

## What it does

- **QwenCloud Token Plan** (`Q`) — remaining 7-day allowance and reset
  countdown, read through a console sign-in.
- **DeepSeek API** (`D`) — balance and the peak / off-peak rate band, read with
  an API key stored in the login keychain.
- One menu bar item that rotates between accounts every minute, so the footprint
  stays at one reading no matter how many accounts you add. It turns red when an
  account is running low, and grey with a `⚠` when a refresh failed.
- Click it and every account is shown at once, each with its own actions.
- Low-balance notifications, launch at login, and a per-account "show in menu
  bar" toggle.
- A daily check for new versions. It only tells you one exists — nothing is
  downloaded or installed for you, and it can be turned off in Settings.

Credentials never leave your machine, and there is no analytics or telemetry.

## Install

1. Download `TokenBar-1.0.0.dmg` below and open it.
2. Drag `TokenBar.app` onto the `Applications` shortcut, then eject the image.
3. **First launch only** — the app is not notarized by Apple (that requires a
   paid Developer ID), so macOS quarantines it. Clear the flag once:

   ```bash
   xattr -dr com.apple.quarantine /Applications/TokenBar.app
   ```

   Then open it normally, or right-click the app → **Open** → **Open**.

Requires macOS 13 or later. The binary is universal (Apple Silicon and Intel).
