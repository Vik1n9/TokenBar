QwenCloud moved Token Plan quotas from a weekly window to a monthly one, and
the usage endpoint renamed its fields to match (`per1WeekPercentage` became
`per1MonthPercentage`). TokenBar only knew the weekly names, so after the
switch the QwenCloud reading showed `Q ?` with no reset countdown.

## What changed

**QwenCloud reads whatever quota window the plan uses.** Any
`per<N><Unit>Percentage` / `per<N><Unit>ResetTime` pair the console returns is
picked up — hourly, daily, weekly or monthly — so the next change of window
does not break the reading again.

```
Q  QwenCloud Token Plan
   Monthly allowance           100% left
   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
   Resets in 7d
```

- Each window gets its own labelled row (`Monthly`, `7-day`, `5-hour`, …)
  instead of a hard-coded "7-day".
- If a plan ever reports more than one window at once, the menu bar shows the
  one with the least left — that is the one that will stop requests first.

DeepSeek is unchanged.

## Install

Download the `.dmg`, drag `TokenBar.app` into `Applications`, replacing the
existing copy, then clear the quarantine flag once — the app is **not
notarized** (that needs a paid Apple Developer ID), so macOS will otherwise
refuse to open it:

```bash
xattr -dr com.apple.quarantine /Applications/TokenBar.app
```

Your API key and QwenCloud session are untouched by the upgrade. Universal
binary (Apple Silicon + Intel), macOS 13 or later.
