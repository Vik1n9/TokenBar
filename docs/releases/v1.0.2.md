1.0.1 trimmed the drop-down but did not fix its contrast: macOS washes out the
title of a disabled menu item however it is coloured, and every information row
in TokenBar is disabled — they are readings, not commands. So the menu still
came out looking greyed out.

This release stops using menu text for those rows and draws them instead.

## What changed

**Each account is a card.** The rows are custom views now, so they render at
full contrast, unclickable as before:

```
Q  QwenCloud Token Plan
   7-day allowance              42% left
   ▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░
   Resets in 2d
   Open Console
   Sign Out
───────────────────────────────────────
D  DeepSeek API
   Balance                       ¥110.00
   Off-peak (50% off) · peak in 4h
   Open Usage Page
```

- The number sits on the right in a semibold monospaced-digit face, so it stays
  put as it changes; its label sits on the left.
- QwenCloud's remaining allowance gets a bar, because it is a share of
  something. A currency balance does not — there is no full mark to measure a
  balance against — so DeepSeek shows the figure alone.
- The bar and the number turn red when the allowance is nearly gone, or when the
  balance is under the threshold set in Settings.
- Context lines (reset countdown, rate band) are smaller and quieter than the
  numbers they belong to.
- Each account's own actions now share the card's left margin instead of being
  indented under it — the heading above already says whose they are.

Everything the menu shows is unchanged from 1.0.1; only how it is drawn.

## Install

Download the `.dmg`, drag `TokenBar.app` into `Applications`, replacing the
existing copy, then clear the quarantine flag once — the app is **not
notarized** (that needs a paid Apple Developer ID), so macOS will otherwise
refuse to open it:

```bash
xattr -dr com.apple.quarantine /Applications/TokenBar.app
```

Your API key and QwenCloud session are untouched by the upgrade. Universal
binary (Apple Silicon + Intel), macOS 13 or later.
