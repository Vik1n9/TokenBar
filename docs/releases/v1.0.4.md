Other programs on your Mac can now read what TokenBar last saw. A script that
checks your remaining allowance before it dispatches no longer has to call the
provider APIs itself — TokenBar writes its latest readings to a small JSON
status file after every successful refresh.

## What changed

**TokenBar exports a status file.** After each successful refresh the app
writes:

```
~/Library/Application Support/TokenBar/status.json
```

```json
{
  "version": 1,
  "updatedAt": "2026-10-19T12:00:00+08:00",
  "qwen": {
    "percentLeft": 42.0,
    "windows": [
      { "label": "Monthly", "hours": 720, "percentLeft": 42.0, "resetsAt": "2026-10-21T00:00:00+08:00" }
    ],
    "at": "2026-10-19T12:00:00+08:00"
  },
  "deepseek": {
    "USD": { "total": 17.13, "toppedUp": 16.8, "granted": 0.33, "at": "2026-10-19T12:00:00+08:00" },
    "CNY": { "total": 5.11, "toppedUp": 0, "granted": 5.11, "at": "2026-10-19T12:00:00+08:00" }
  }
}
```

- `qwen.percentLeft` is the smallest percentage left across that account's
  quota windows — the allowance that will stop requests first. `windows` lists
  every window the plan reports.
- `deepseek` holds one object per wallet, keyed by ISO currency code.
- Timestamps are ISO 8601. `updatedAt` is when the file was written; each
  account's `at` is when its numbers were actually read. If a refresh fails,
  that account's previous numbers and `at` are kept rather than overwritten
  with zero.
- The export is controlled by a new toggle, **Settings → General → Export
  status file for other apps to read** (on by default). Turning it off deletes
  the existing file.
- The file holds numbers, ISO currency codes and timestamps only — no API key,
  cookie, session token or any other identifier is ever written, and it is
  created with `0600` permissions so only your user can read it.

The QwenCloud and DeepSeek readings themselves are unchanged.

## Install

Download the `.dmg`, drag `TokenBar.app` into `Applications`, replacing the
existing copy, then clear the quarantine flag once — the app is **not
notarized** (that needs a paid Apple Developer ID), so macOS will otherwise
refuse to open it:

```bash
xattr -dr com.apple.quarantine /Applications/TokenBar.app
```

Your API key and QwenCloud session are untouched by the upgrade. Universal
binary (Apple Silicon + Intel), macOS 13 or later.
