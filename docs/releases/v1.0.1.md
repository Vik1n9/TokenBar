A readability release: the drop-down was hard to read and said more than it
needed to. Same accounts, same data, much less of it on screen.

## What changed since 1.0.0

**The drop-down is legible again.** Its rows are informational and therefore
disabled, which macOS drew washed out — the whole menu read as greyed-out text.
Every row now sets its own colour, so it stays unclickable at normal contrast.

**Only the numbers that move.** Each account shows what is left and when that
changes, and nothing else:

```
Q  QwenCloud Token Plan          D  DeepSeek API
     Left: 42%                        Balance: ¥110.00
     Resets in 2d                     Off-peak (50% off) · peak in 4h
     Open Console                     Open Usage Page
     Sign Out
```

Gone from the menu: plan tier, status, expiry, remaining days and auto-renew for
QwenCloud; today / this month / last 7 days spend, the runway estimate, the
token count and the granted-versus-topped-up split for DeepSeek. Most of those
were estimated from balance movements rather than reported, and a menu full of
estimates is harder to read than one number that is exact. Today's DeepSeek
spend is still available as an optional second figure in the menu bar title,
from the DeepSeek settings tab.

Rows that are not routine still appear: a wallet that cannot serve API calls, a
second currency, and the "Updated HH:MM:SS" timestamp when the last refresh
failed and the numbers on screen are stale.

**Update notifications.** Once a day TokenBar asks GitHub whether a newer
release exists. If one does, the drop-down grows an **Update available: x.y.z…**
row and a notification is posted once for that version. Clicking the row opens
the release page — nothing is downloaded, replaced or installed for you.
Pre-releases and drafts are ignored. Turn it off, or check on demand, under
**Settings → General → Updates**.

## Install

Download the `.dmg`, drag `TokenBar.app` into `Applications`, replacing the
existing copy, then clear the quarantine flag once — the app is **not
notarized** (that needs a paid Apple Developer ID), so macOS will otherwise
refuse to open it:

```bash
xattr -dr com.apple.quarantine /Applications/TokenBar.app
```

Your API key and QwenCloud session are untouched by the upgrade. Universal
binary (Apple Silicon + Intel), macOS 13 or later.
